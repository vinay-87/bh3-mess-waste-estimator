# AI Chat Logs

This folder has the AI conversations I used during this project. I'm fine with you reading these — the assignment says to include them and I used AI pretty heavily for certain parts.

## Files

- `research-help.md` — Used ChatGPT to find academic sources on institutional food waste and understand why existing solutions (apps, smart scales) don't fit a college mess context. It pointed me to the UNEP Food Waste Index Report.
- `code-help.md` — Used ChatGPT to help write the pandas data processing and terminal output formatting. I described what analysis I wanted and it helped with groupby/agg syntax. Also asked about building a web dashboard before deciding against it.
- `data-structure.md` — Quick chat about how to structure the CSV columns before going to the mess. The notes column suggestion turned out useful.

## What I did vs what AI did

**Me:**
- Identified the problem from living in BH3 and eating in the mess daily
- Went to the mess, talked to Suresh bhaiya, collected all data manually
- Took photos, observed the leftover containers, counted students
- Decided what analysis actually matters for a mess cook who doesn't use a computer
- Wrote the reflection
- Decided thresholds, what items to flag, what output format is useful
- Scrapped the web dashboard idea (AI suggested it, I killed it)

**AI:**
- Helped find the UNEP report and frame the research
- Pandas groupby/aggregation syntax
- Terminal output formatting with f-strings
- Suggested CSV column structure
- Suggested linear regression (I rejected this — 7 days is not enough data for ML)

Didn't use AI for the fieldwork documentation or the reflection.
